**Tide Market** — a merchant trading card game. Buy low, sell high, out-trade the rival Capt. Brine before the 8th sunset. Four goods (Ember Spice ◆, Moon Silk ●, Jade Tea ▲, Tide Pearl ■) ride a shifting tide of prices; hold 3+ of one good to cash in a set bonus ×1.5. A complete game: title screen, a table with your hand and the rival's, readable values and costs, purse and net-worth totals, and win and loss screens — all offline in a desktop browser.

## Run it

```sh
python3 -m http.server --directory game 8000
# open http://localhost:8000 — or serve game/ with any static server
```

Mouse or keyboard: keys 1–4 buy from the market, click a hand card to select (again, or S, to sell), Enter ends the day. 8 days; the richest trader rules the harbor.
